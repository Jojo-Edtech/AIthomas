# UI/UX Review Skill Adaptation Notice

AI Thomas includes a compact, text-only UI/UX review protocol adapted from:

- Project: [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
- Source revision: `abb7f2fd5a083fa1ff55c326a963ff0d95c33f99`
- Copyright: 2024 Next Level Builder
- Upstream license: [MIT License](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/LICENSE)

The adaptation keeps a small subset of the upstream review principles: define the product job, inspect hierarchy and control consistency, check responsive and accessible behavior, account for key interface states, prioritize findings, and state a testable acceptance checklist. AI Thomas does not bundle or execute the upstream CLI, Python scripts, datasets, generated design systems, or third-party packages. The adaptation does not imply endorsement by Next Level Builder.
